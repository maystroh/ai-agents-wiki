# Personal AI Is the New Personal Computer

## Summary

- Gary Tan (YC President) rebuilt his blog platform in 5 days for ~$200 using Claude — vs the original build which cost ~$4M, took a year, and required 6 engineers
- "Boil the ocean" philosophy: agentic software should do exhaustive, complete research rather than sampling the way humans do; thoroughness is now affordable
- OpenClaw described as a "Ferrari" — powerful but requires deep expertise to configure and maintain; not for casual users
- Token maxing reframed: when an agent does comprehensive research, high token counts are a feature, not a waste
- Personal AI = personal computer analogy: the PC democratized computation; personal AI democratizes knowledge work

## Key Insights

- **$200 / 5 days vs $4M / 1 year / 6 people.** This is Tan's primary empirical claim. The productivity multiplier isn't 2× or 10× — it's in the thousands for the right tasks. The 6-person-year to 5-day collapse is the headline.
- **Boil the ocean is the right philosophy for agents.** Humans sample: we read a few sources, make a judgment call. Agents don't need to sample — they can read everything, check all edge cases, verify all assumptions. The cost of thoroughness is now near-zero. "Boil the ocean" means doing the exhaustive version of the task, not the human-grade version.
- **OpenClaw is a tool for experts.** Tan describes OpenClaw as powerful but high-maintenance — a Ferrari that needs a dedicated mechanic. This positions it in contrast with more approachable agent harnesses. The lesson: the best tools aren't always the most accessible tools.
- **Token maxing is legitimate when doing complete research.** Tan connects high token usage to the "boil the ocean" philosophy. If you're doing exhaustive research, you should be using a lot of tokens — that's the work. Token maxing only becomes problematic if tokens are consumed without proportional output.
- **Personal AI = personal computer.** The PC didn't just make existing work faster — it created new categories of work. Tan argues personal AI does the same: it doesn't just assist developers, it enables non-developers to build and operate software businesses.
